# ChemWorkBench v2 Overview

ChemWorkBench v2 is a unified scientific analysis platform designed to support:

- UV-Vis
- IR
- NMR
- MS
- Future techniques such as CV, Raman, EPR, XRD, GC×GC, MS imaging, and more

The architecture is built around:

- A universal math layer
- A thin processor layer
- A config-driven pipeline
- A three-tier plotting engine
- A canonical data model
- A plugin-ready registry system

This document provides a high-level overview. See `/docs/architecture/` for detailed breakdowns.
